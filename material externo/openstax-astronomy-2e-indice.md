## Uso recomendado en compendios

Cuando se actualice un compendio con referencias a este libro:

1. Priorizar primero el contenido del diplomado y usar OpenStax como apoyo introductorio o de contraste.
2. Enlazar a la seccion web especifica cuando el tema sea preciso; si solo se conoce el capitulo, enlazar a la URL de capitulo en este indice.
3. Marcar claramente las notas externas, por ejemplo como **Referencia OpenStax** o **Complemento OpenStax**.
4. Parafrasear y sintetizar; si se copia texto literal, usar cita breve y atribucion.
5. Mantener la atribucion bibliografica a OpenStax y respetar la licencia del libro.
